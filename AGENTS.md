# Instructions for coding agents

Codex-style tools load `AGENTS.md` from the repository root, so this short
pointer stays here. The human-facing entry points are [`README.md`](README.md)
and [`RESULTS.md`](RESULTS.md).

Before changing anything, read the full agent operating rules in
[`docs/process/AGENTS.md`](docs/process/AGENTS.md). Bare file names in that
document (`PRD.md`, `REPO_MAP.md`, `TASK.md`) refer to files in
[`docs/process/`](docs/process/README.md); `TASK_STATE.md`, `METHODOLOGY.md`
and `FINANCEIQ_AGENT_TASK_QUEUE.md` remain at the repository root.
