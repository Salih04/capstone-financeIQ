Project context:

Goal:
Create a daily limited market news feature.

Backend requirements:
1. Implement or update GET /news/updates.
2. Fetch finance/trading/market news from an external provider through the backend only.
3. Do not expose API keys on the frontend.
4. Return 3 news articles per request.
5. Support pagination/refresh with a query parameter like:
   - /news/updates?page=1
   - /news/updates?page=2
   - /news/updates?page=3
6. Maximum page should be 3, meaning max 9 articles per day.
7. Use backend caching so the external API is not called unnecessarily.
8. Cache news by date and page.
9. Each article should include:
   - id
   - title
   - source
   - published_at
   - summary
   - url
   - sentiment or ai_insight if available
10. If the external API fails, return a safe fallback response with a clear message instead of crashing.

Frontend requirements:
1. Update /news page.
2. On first load, fetch page=1 and show 3 articles.
3. Add a “Refresh News” button.
4. The user can click refresh maximum 2 times per day.
5. Each click loads the next page and appends 3 more articles.
6. Total visible articles must never exceed 9.
7. Store refresh count, current page, shown article IDs, and date in localStorage.
8. Reset localStorage automatically when the date changes.
9. Disable the refresh button after:
   - 2 refreshes, or
   - 9 articles are shown.
10. Show a small status text:
   - “3 / 9 news shown”
   - “Refreshes left: 2”
