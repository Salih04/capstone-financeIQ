# Historical Documentation Archive

The `docs/archive/` directory is the future home for historical documentation
that is useful for understanding how FinanceIQ evolved but is not part of the
active operating surface. Archive is preservation, not deletion: dated
validation, investigation, strategy, review, and governance context may remain
here so later readers can audit decisions and evidence.

Canonical scientific generated artifacts remain in their producer-owned
locations. They are not moved into this archive. Any future archive relocation
must update inbound references and must preserve the original historical
evidence without rewriting it to match current state.

Intended categories:

- `audits/`
- `investigations/`
- `reviews/`
- `spikes/`
- `strategy/`
- `verification/`

- `spikes/E2E_AUTH_SPIKE.md` — completed authenticated-E2E feasibility record.

No historical document is moved by the initial scaffold.
