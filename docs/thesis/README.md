## Regenerating the baseline

```
make thesis-baseline
```

The record embeds `source_artifacts` checksums for every frozen input, so
`tests/test_artifact_registry.py::test_embedded_source_artifact_checksums_are_current`
re-verifies the freeze on every root-suite run. If a governed input drifts, that
test fails and names the file — the freeze is a tripwire, not a snapshot.

## Claim discipline

Everything here is descriptive research provenance. It establishes no
predictive edge and no investment value, and it is not investment advice. The
repository's finding — walk-forward IC statistically indistinguishable from zero
after multiplicity correction — stands.
